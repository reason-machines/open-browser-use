# Full-stack integration: daemon ↔ Go host ↔ extension wire v2 (r2-integrate)

- Daemon consumes wire v2: feature detection (`capabilities.wire`), `route.profileId`, guarded `closeTab` (`force` for agent-initiated closes), push notifications (`tabClosed`, `leaseRevoked`, `popupOpened`, `sessionExpired`, `debuggerAttached/Detached`, `onDownloadChange`) → SystemEvents; the 3 s `getTabs` poll is gone on v2 extensions. Idle-detach wipes CDP state → the attach sequence re-runs on the next call.
- Downloads: browser-level path from chrome.downloads (extension) or `Browser.downloadProgress` (direct backend with `--downloads-dir`), per tab; WS-E's tracker resolves real paths via `configureDownloads`; the repl no longer re-fetches. `wait{for: download|popup|dialog}` also returns an unclaimed event from the last 10 s (fast downloads land before the wait call), each event once.
- Popups are adopted only with `Page.windowOpen` evidence from an agent tab: the user's own Cmd+T / link opens from an agent tab are never taken (and are ungrouped).
- Focus: focus emulation also on OOPIF child sessions during a call (cross-process element focus brought Chrome to the front); clicks inside frames nested in OOPIFs map coordinates through each local root.
- An act whose tab closes itself (OAuth popup) succeeds with `tab_closed`; a restarted daemon finalizes un-renewed sessions after 10 s.
- New: `test/fullstack-live.mjs` (supervised daemon + real host + Reason extension, focus sampler, D6 latencies), `scripts/install-local-agent.sh` + `docs/agent/INSTALL-LOCAL.md` (side-by-side install on the user's real Chrome), `brands/reason-agent.json`. Fixed: daemon never started from a path with spaces/symlinks (entry guard); e2e harness wrote `relay.token`/`active.json` into the user's `/tmp/open-browser-use`.
